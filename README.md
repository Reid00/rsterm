# RSTerm - 现代化跨平台 SSH 终端工具
**基于 Rust 开发，融合 Xshell 稳定 + WindTerm 轻量免费，内置 SFTP、多标签分屏、高性能远程运维终端**

A Modern Cross-Platform SSH Terminal Built with Rust.
---

## 🌟 项目简介
RSTerm 是一款**纯 Rust 开发**的现代化跨平台 SSH 客户端工具，专为开发、运维、后端工程师设计。
它整合了行业主流工具 **Xshell**（成熟稳定）与 **WindTerm**（轻量免费、内置 SFTP）的核心优势，主打：
✅ 跨平台（Windows / macOS / Linux）
✅ 秒级启动、超低内存占用
✅ 无需外置工具，**原生内置 SFTP**
✅ 多标签 / 多窗口 / 分屏
✅ 安全加密、本地优先、无数据上传

---

## ✨ 核心特性
### 🔌 连接与协议
- 支持标准 **SSH2** 远程连接
- 支持**密码 / OpenSSH 私钥**登录
- 支持**跳板机（Jump Host）**、SOCKS5 / HTTP 代理
- 会话管理：分组、保存、重命名、快速连接
- 断线自动重连、心跳保活防断开

### 🖥️ 终端体验
- 多标签页切换，支持标签颜色标记
- 一键水平/垂直分屏，鼠标拖拽调整大小
- 自定义字体、字号、主题、透明度
- 支持 xterm-256color、UTF-8 完整编码
- 右键快捷复制/粘贴、清屏、重置终端

### 📂 内置 SFTP 文件管理（核心亮点）
- **无需第三方工具**
- 左右双面板：本地文件 ↔ 远程文件
- 拖拽上传/下载、传输进度实时显示
- 支持新建、删除、重命名、修改权限
- 支持大文件传输、断点续传（规划中）

### ⚡ 效率增强
- 命令历史记录 + 搜索
- 常用命令收藏、快速执行
- 多会话**同步输入**，批量执行命令
- 端口转发（本地/远程/动态）
- 会话日志自动保存、可检索

### 🔒 安全与性能
- 密码/密钥**本地加密存储**，不上传云端
- 纯 Rust 编写，内存安全、无崩溃
- 启动速度 < 1s，内存占用 < 150MB
- 长时间稳定连接不卡顿

### 🎨 跨平台与定制
- 原生支持 Windows 10+ / macOS 11+ / Linux
- 深色/浅色主题自由切换
- 全局快捷键自定义
- 配置文件可导出/备份

## 🚀 快速开始
### 1. 下载安装
前往 [Releases](https://github.com/yourname/rsterm/releases) 下载对应系统安装包：
- Windows：安装包 / 便携版
- macOS：DMG 镜像
- Linux：deb / rpm / 压缩包

### 2. 首次使用
1. 打开 RSTerm
2. 新建会话：输入主机IP、端口、用户名、认证方式
3. 点击连接，直接进入终端
4. 右侧一键打开 SFTP 文件管理面板

### 3. 基础操作
- 新建标签：`Ctrl + T`
- 分屏：`Ctrl + Alt + →/↓`
- SFTP 开关：`Ctrl + L`
- 复制：`Ctrl + C` / 右键复制
- 粘贴：`Ctrl + V` / 右键粘贴

## 🛠️ 技术栈
- **开发语言**：Rust
- **SSH 协议**：russh / ssh2-rs
- **UI 框架**：egui（原生GUI）
- **异步运行时**：tokio
